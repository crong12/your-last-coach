# Triage labels

Every triaged issue carries exactly one category role and one state role. The canonical role and GitHub label are intentionally identical.

## Category roles

| Canonical role | GitHub label |
| --- | --- |
| bug | `bug` |
| enhancement | `enhancement` |

## State roles

| Canonical role | GitHub label |
| --- | --- |
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

An unlabeled issue normally enters `needs-triage`. From there it moves to `needs-info`, `ready-for-agent`, `ready-for-human`, or `wontfix`. When requested information arrives, move `needs-info` back to `needs-triage` for re-evaluation.

Triage-generated issue bodies and comments must begin with:

> *This was generated by AI during triage.*
